# Supermart-Grocery-Sales-Power-Bi
Power BI dashboard project for Supermart Grocery Sales analysis, including customer, regional, and profitability insights.
## Project Overview

This project analyzes Supermart grocery sales data from 2015 to 2018 using Microsoft Power BI. It presents interactive dashboards to understand sales performance, customer behavior, regional performance, and profitability.

## Tools & Technologies

Microsoft Power BI

DAX (Data Analysis Expressions)

Data Visualization

Data Cleaning and Data Analysis
